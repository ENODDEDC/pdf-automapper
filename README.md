# 📄 PDF AutoMapper Pro

Visual PDF form automation tool with drag-and-drop field mapping.

## ✨ Features

- 🎨 **Visual Field Mapping** - Draw boxes directly on PDF templates
- ⚡ **Smart Text Fitting** - Auto-adjusts font size and wraps text
- 🔄 **Template Reusability** - Save field mappings for reuse
- 🎯 **Multi-Select** - Copy multiple fields at once
- ⌨️ **Keyboard Controls** - Precise positioning with arrow keys
- 🎭 **Live Preview** - See results before generating PDF

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/pdf-automapper.git
cd pdf-automapper

# Install dependencies
pip install -r requirements.txt

# Run the application
python box_pdf_filler_pro.py
```

## 📖 How to Use

1. **Load Template** - Click "📁 Template" to select your PDF
2. **Draw Fields** - Click and drag to create field boxes
3. **Adjust** - Use arrow keys for precise positioning
4. **Fill Data** - Click "✏️ Fill" to enter your data
5. **Preview** - Review before generating
6. **Export** - Save your filled PDF

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Arrow Keys` | Move selected fields (1px) |
| `Ctrl + Arrows` | Move fields faster (10px) |
| `Shift + Arrows` | Resize selected fields |
| `Ctrl + Click` | Multi-select fields |
| `Double Click` | Rename field |
| `ESC` | Clear selection |
